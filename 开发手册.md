## 1. 项目概述

### 1.1 项目简介

QIAN-PPT 是一个基于 **Flask + Fabric.js** 的瑞士风格幻灯片编辑器与展示系统。支持可视化编辑幻灯片（960×540 画布）、全屏演示、导出独立 HTML。

### 1.2 核心特性

- **Agent 友好**：支持利用各类 Agent 工具生成 PPT（Codex、Antigravity、Claude Code、Trae 等）
- **人工自由编辑**：提供完整的 Web 可视化编辑器，可随时介入调整
- **丰富的元素系统**：支持添加文本、形状、小组件、图标等各类元素
- **灵活的属性控制**：自由调整颜色、透明度、位置、大小等属性
- **内置 CLI 工具链**：一整套命令行工具，方便 Agent 精确编辑 PPT
- **多工作区支持**：支持创建和管理多个独立的幻灯片项目
- **自动备份**：每次保存自动创建备份，防止数据丢失
- **组件系统**：内置多种预设组件，一键插入使用

### 1.3 设计理念

项目采用瑞士国际主义设计风格，强调：
- 网格系统的严谨性
- 排版的清晰度
- 色彩的克制使用
- 功能的实用性

### 3.1 关键文件说明

#### app.py
Flask 后端核心文件，包含：
- 路由定义（页面路由 + API 路由）
- 工作区管理逻辑
- 幻灯片 CRUD 操作
- 元素级 CRUD 操作
- 文件上传处理
- 组件渲染 API
- 导出功能

#### templates/editor.html
编辑器前端页面，包含：
- 三栏布局（左侧幻灯片列表、中间画布、右侧属性面板）
- Fabric.js 画布初始化
- 元素交互逻辑
- 属性面板绑定
- 工具栏功能

#### templates/presentation.html
展示页面，包含：
- 全屏幻灯片展示
- 翻页动画
- WebGL 背景效果
- 响应式布局

## 5. 核心功能模块

### 5.1 工作区管理

#### 5.1.1 功能说明

支持创建和管理多个独立的幻灯片项目，每个工作区包含：
- 独立的幻灯片数据
- 独立的备份文件
- 独立的导出文件
- 独立的截图文件

#### 5.1.2 工作流程

1. **创建工作区**
   - 通过 API 或 UI 创建新工作区
   - 自动创建目录结构
   - 初始化元数据

2. **切换工作区**
   - URL 参数：`?workspace=<workspace_id>`
   - 默认工作区：`default`

3. **删除工作区**
   - 默认工作区不可删除
   - 删除前确认提示
   - 清理相关目录

### 5.6 导入导出

#### 5.6.1 导出功能

导出为独立 HTML 文件：
- 包含所有幻灯片数据
- 包含所有样式和脚本
- 可直接用浏览器打开
- 无需服务器支持

导出路径：`data/workspaces/<workspace_id>/ppt/index.html`

#### 5.6.2 导入功能

支持两种导入模式：
- **替换模式**：覆盖当前工作区所有数据
- **追加模式**：在当前工作区末尾添加幻灯片

导入时自动重写 ID，避免冲突。

### 5.7 备份系统

#### 5.7.1 自动备份

每次保存自动创建备份：
- 备份路径：`data/workspaces/<workspace_id>/backups/`
- 备份命名：`slides_YYYYMMDD_HHMMSS.json`
- 保留最近 10 个备份

#### 5.7.2 备份恢复

当主数据文件损坏时：
- 自动检测 JSON 格式错误
- 从最近的备份恢复
- 提示用户恢复成功

### 5.8 文件上传

#### 5.8.1 支持格式

- 图片：png, jpg, jpeg, gif, webp, svg
- 视频：mp4, webm

#### 5.8.2 上传流程

1. 选择文件
2. 验证文件类型和大小（最大 50MB）
3. 添加时间戳避免冲突
4. 保存到 `static/uploads/`
5. 返回访问 URL

    wid = normalize_workspace_id(workspace_id)
    data_file = workspace_data_file(wid)
    backup_folder = workspace_backup_folder(wid)

    # 备份当前数据
    if os.path.exists(data_file):
        try:
            with open(data_file, 'r', encoding='utf-8') as f:
                json.load(f)  # 验证 JSON 有效性
            ts = datetime.now().strftime('%Y%m%d_%H%M%S')
            backup_path = os.path.join(backup_folder, f'slides_{ts}.json')
            shutil.copy2(data_file, backup_path)
            
            # 只保留最近 10 个备份
            backups = sorted([f for f in os.listdir(backup_folder) if f.startswith('slides_')])
            for old in backups[:-10]:
                os.remove(os.path.join(backup_folder, old))
        except Exception as e:

    # 保存新数据
    with open(data_file, 'w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)

def batch_operations(slide_id, operations):

    data = load_slides()
    slide_idx, slide = find_slide(data, slide_id)

                results.append({"action": "delete", "status": "ok"})
            
            else:
                results.append({"action": action, "status": "error", "error": "Unknown action"})

            results.append({"action": action, "status": "error", "error": str(e)})
    
    save_slides(data)

from werkzeug.utils import secure_filename

@app.route('/api/upload', methods=['POST'])
def upload_file():
    if 'file' not in request.files:
        return jsonify({"error": "No file"}), 400
    
    file = request.files['file']

def sanitize_text_in_data(data):
    """清理数据中的转义字符"""
    if isinstance(data, dict):
        return {k: sanitize_text_in_data(v) for k, v in data.items()}
    elif isinstance(data, list):
        return [sanitize_text_in_data(item) for item in data]
    elif isinstance(data, str) and '\\n' in data:
        return data.replace('\\n', '\n').replace('\\t', '\t')
    return data

### 9.8 导入功能

#### 9.8.1 数据校验

```python
def normalize_import_data(data):
    """校验并规范化导入数据"""
    if not isinstance(data, dict):
        return None, "导入数据必须是 JSON 对象"
    
    slides = data.get('slides')
    if not isinstance(slides, list):
        return None, "导入数据缺少 slides 数组"
    
    normalized = copy.deepcopy(data)
    normalized.setdefault('settings', {})
    
    for i, slide in enumerate(normalized['slides']):
        if not isinstance(slide, dict):
            return None, f"第 {i + 1} 页幻灯片必须是 JSON 对象"
        
        slide.setdefault('id', generate_slide_id())
        slide.setdefault('layout', '')
        slide.setdefault('theme', 'light')
        slide.setdefault('backgroundColor', '#fafaf8')
        slide.setdefault('canvas_elements', [])
        
        if not isinstance(slide['canvas_elements'], list):
            return None, f"第 {i + 1} 页 canvas_elements 必须是数组"
    
    return normalized, None
```

#### 9.8.2 ID 重写

```python
def rewrite_import_ids(imported_data, existing_data):
    """重写导入数据的 ID，避免冲突"""
    existing_slide_ids = {str(s.get('id')) for s in existing_data.get('slides', [])}
    existing_elem_ids = {
        str(e.get('id'))
        for s in existing_data.get('slides', [])
        for e in s.get('canvas_elements', [])
    }
    
    rewritten = copy.deepcopy(imported_data)
    
    for slide in rewritten.get('slides', []):
        # 重写幻灯片 ID
        new_slide_id = generate_slide_id()
        while new_slide_id in existing_slide_ids:
            new_slide_id = generate_slide_id()
        slide['id'] = new_slide_id
        existing_slide_ids.add(new_slide_id)
        
        # 重写元素 ID
        for elem in slide.get('canvas_elements', []):
            new_elem_id = generate_elem_id()
            while new_elem_id in existing_elem_ids:
                new_elem_id = generate_elem_id()
            elem['id'] = new_elem_id
            existing_elem_ids.add(new_elem_id)
    
    return rewritten
```

@app.route('/api/import', methods=['POST'])
def import_data():
    """导入幻灯片数据"""
    workspace_id = normalize_workspace_id()
    body = request.get_json() or {}
    mode = body.get('mode')
    
    if mode not in ('replace', 'append'):
        return jsonify({"error": "mode must be replace or append"}), 400

        return jsonify({"error": error}), 400

    else:

        next_data = copy.deepcopy(current)
        next_data['slides'].extend(appended.get('slides', []))
    
    version = save_slides(next_data, workspace_id)
    
    return jsonify({
        "status": "ok",
        "workspace": workspace_id,
        "_version": version,
        "mode": mode,

    })

// 禁用不必要的渲染
canvas.perfLimitSizeTotal = 2097152;

### D. API 快速参考

**工作区**
- `GET /api/workspaces` - 获取工作区列表
- `POST /api/workspaces` - 创建工作区
- `PUT /api/workspaces/<id>` - 重命名工作区
- `DELETE /api/workspaces/<id>` - 删除工作区

**幻灯片**
- `GET /api/slides` - 获取所有幻灯片
- `POST /api/slides` - 保存所有幻灯片
- `POST /api/slides/create` - 创建幻灯片
- `PUT /api/slides/<id>` - 更新幻灯片
- `DELETE /api/slides/<id>` - 删除幻灯片

**元素**
- `GET /api/slides/<id>/elements` - 获取元素列表
- `POST /api/slides/<id>/elements` - 添加元素
- `PUT /api/slides/<id>/elements/<id>` - 更新元素
- `DELETE /api/slides/<id>/elements/<id>` - 删除元素
- `POST /api/slides/<id>/elements/batch` - 批量操作

**文件**
- `POST /api/upload` - 上传文件
- `GET /api/image-info` - 获取图片信息

**组件**
- `GET /api/components` - 获取组件列表
- `POST /api/components/render` - 渲染组件
- `POST /api/components/custom` - 添加自定义组件

**导出导入**
- `GET /api/export` - 导出 HTML
- `POST /api/import` - 导入数据
